# 6-7 Man

Third-person voxel prototype built with Three.js.

**Play:** https://austenc.github.io/six-seven-man/

## Run locally

```bash
npm install
npm run dev
```

## Controls

- **WASD** — move
- **Mouse** — look / aim (crosshair)
- **Space** — jump
- **Shift** — sprint
- **E** — open loot crate
- **Left click** — attack (sword: overhead · spear: two-handed thrust)
- **1–4** — hotbar equip
- **I** — inventory

## Features

- Bald, 6'7" voxel hero with pot belly + walk cycle
- Procedurally generated urban city
- Dessert **enemies**: carrot cake, ice cream, cookie monsters
- Vegetable weapons: Carrot Sword, Asparagus Spear (2H)
- Hotbar / inventory, score, combo, SFX, game over + restart
