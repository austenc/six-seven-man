# 6-7 Man

Third-person voxel prototype built with Three.js.

**Play:** https://austenc.github.io/six-seven-man/

## Run locally

```bash
npm install
npm run dev
```

## Controls

- **WASD** — move
- **Mouse** — look / aim (crosshair)
- **Space** — jump (hop rolling donuts)
- **Shift** — sprint
- **E** — open loot crate
- **Left click** — attack
- **1–5** — hotbar equip
- **I** — inventory

## Features

- Bald, 6'7" voxel hero with pot belly + walk cycle
- Procedurally generated urban city
- Dessert **enemies**: carrot cake, ice cream, cookie monsters, hostile donuts
- Vegetable weapons: Carrot Sword, Asparagus Spear (2H), Broccoli Mace (2H cleave), Jalapeño Popper (ranged)
- Generous melee cones + full-body hit capsules
- Hotbar / inventory, score, combo, SFX, game over + restart
